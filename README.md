## 生存流程

1. 制作时序探针，右键寻找观测台。潜行右键重新搜索，普通右键读取已保存坐标。
2. 带刷子，从观测台入口的可疑沙子取得时序尘。读取机关旁的线索台；潜行右键普通刻印台可以先读含义。
3. 完成观测台三间房，领取过去记录、过去印记和编年残页。
4. 制作研究台：记录槽放过去记录，样本槽放时序尘，参照槽放书。研究得到过去时序结论，原记录保留。
5. 升级档案探针，进入地下档案馆。完成排序、镜像和钟声试验，激活并击败失序抄写员。
6. 用现在记录 + 紫水晶碎片 + 过去结论研究现在结论。记录和作为参照的过去结论保留。
7. 制作零点探针、空白印记和零刻钥匙。进入钟室，以过去、现在、空白印记依次扫描三座刻印台。扫描不消耗印记。
8. 持钥匙启动编年者。开场及第一幕每个分段的四相护盾顺序随机，需要试出并依次点亮。详细战斗线索在房间的档案台。
9. 第一幕五段结束后，在白金圣域继续第二幕平台追逐战。击败第二幕后返回原场地领取时代核心和未来记录。在研究台放未来记录 + 编年残页 + 时代核心，完成终末研究。记录和核心保留。

研究会保留可复用的原件，所以合成探针或钥匙消耗结论后，可返回研究台制作新的结论。只有样本槽以及配方明确标注的输入会被消耗。

## 模组配置

`config/time-common.toml`：

- `bossHealth`：默认 900；额外玩家每人增加 35%，最多按四人计算。
- `bossSecondPhaseHealth`：第二幕独立血量，默认 500，不乘队伍倍率。4–5 格高差的平台不会附送跳跃效果，需要整合包已有的移动能力。
- `bossDamage`：默认 10，之后仍受伤害结算和整合包机制影响。
- `echoCount`：过去阶段每轮生成的记忆残响数量，默认 3，范围 1–12。
- `echoHealth`：每个时间残响的生命值，默认 18，范围 1–1000。
- `retryDelaySeconds`：退出战斗后的恢复时间，默认 15 秒。
- `locatorRadius`：结构搜索半径，默认 80 区块。
- `soulForgeAgeBridge`：默认关闭。开启时只修改已存在的 `timeCount` / `timeCountMax`；整合包应负责检查沙漏是否正在装备，推荐通过事件接入。
